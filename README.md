# Sandyprc Homebrew tap

Homebrew cask for **[Service Bus Studio](https://github.com/Sandyprc/sbs)**, a native Mac app for Azure Service Bus.

```sh
brew install --cask sandyprc/tap/service-bus-studio
```

Screenshots, downloads, first-launch help and release notes: **[github.com/Sandyprc/sbs](https://github.com/Sandyprc/sbs)**.
